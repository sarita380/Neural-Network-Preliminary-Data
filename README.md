# Neural Network & Deep Learning

This project implements linear regression and neural network training concepts from scratch using Python and NumPy.

## Project Overview
The assignment explores fundamental deep learning concepts including:
- Linear regression using the Normal Equation
- Gradient computation
- Stochastic Gradient Descent (SGD)
- Batch training analysis
- Model evaluation and prediction

The project uses weather data to predict temperature values based on humidity and visibility features.

## Features
- Linear regression implementation without machine learning libraries
- Data standardization and preprocessing
- Mini-batch, large-batch, and full-batch training
- Training loss visualization
- SGD optimization
- Test set evaluation using Mean Squared Error (MSE)

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Results
- Successfully trained regression models using different batch sizes.
- Compared training performance between small, large, and full batch training.
- Achieved a Test MSE of approximately 0.0159 using the small batch model.
- Visualized training loss across 30 epochs for performance analysis.

## Learning Outcomes
- Understanding gradient descent optimization
- Comparing batch size effects on model convergence
- Implementing machine learning algorithms from scratch
- Evaluating regression model performance
